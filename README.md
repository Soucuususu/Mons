# MONS: Ecos de Aurora

Um RPG original de captura de criaturas em pixel art, feito em HTML/CSS/JavaScript puro. Não usa assets oficiais de Pokémon.

## Como jogar localmente
Abra `index.html` em um navegador moderno. No celular, use o direcional na parte inferior; no PC, use as setas ou WASD.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e abra a URL indicada pelo GitHub Pages.

## Controles
- Setas / WASD: mover
- A / Espaço / Enter: interagir ou fechar diálogo
- Botões na tela: mochila, diário, mapa, descanso e salvar
- Batalha: escolher movimento, lançar orbe ou recuar

## O que já funciona
- Mundo explorável com tiles pixel art e personagem animado
- Grama alta com encontros aleatórios
- Criaturas originais com sprites desenhados em canvas
- Batalha por turnos, HP, XP e subida de nível
- Captura por orbes, equipe de até três criaturas
- Efeitos sonoros sintetizados pelo navegador
- Mochila, diário, mapa, descanso e salvamento local

## Próximos passos recomendados
Expandir a região, adicionar mais criaturas/ataques, NPCs, música original, interiores e uma tela de equipe. O protótipo é deliberadamente autocontido para facilitar o envio pelo celular.
